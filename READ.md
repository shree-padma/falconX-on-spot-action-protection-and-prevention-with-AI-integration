# FALCONX – Forest Protection System

## Overview
FALCONX is a proposed AI-enabled forest monitoring system intended to help detect forest fires, illegal activities, wildlife threats, and environmental changes.

## Current Prototype
This version provides a browser-based dashboard with simulated forest zones and example alerts. It does not connect to physical drones or perform real AI detection.

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Click "Generate Demo Alert" to test the interface.

No installation, API key, or environment variables are required.

## Repository Structure
- index.html: interactive demo
- README.md: setup and overview
- ARCHITECTURE.md: system design
- sample-data.json: sample monitoring data
- TEST_CASES.md: test scenarios
- LICENSE: MIT license
